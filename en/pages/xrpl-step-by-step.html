XRPL step by step

This is a quick path for your first hands-on experience on the XRP Ledger. If you want the broader context first, start with the beginner's guide.

1. Create a testnet account

Visit the official XRPL faucet resources and generate a test account.

2. Inspect the account on XRPScan

Copy the address and open it on XRPScan to see the balance, sequence number, and transactions.

3. Send your first transaction

Use the official developer tools to build a simple payment on testnet.

FAQ

Common questions

Quick testnet-related answers.

Do I need to install anything?

No. You can use official web tools to test the network.

Is the testnet safe?

Yes. The XRP used there has no real financial value and exists only for testing.

Can I do this on mobile?

Yes. Most of the basic tools work from a mobile browser as well.
